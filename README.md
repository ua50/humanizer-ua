# humanizer-ua

Навичка для ШІ-асистентів (Claude та інших агентів, що підтримують формат SKILL.md). Вона виправляє українські тексти та службові документи так, щоб вони не виглядали написаними ШІ.

Автор: ua50. Ліцензія MIT.

## Що робить навичка

- Прибирає штампи, канцелярит і порожні оцінки («ключовий», «всебічний», «відіграє важливу роль»).
- Повертає дію в дієслово: «здійснити перевірку» стає «перевірити», «з метою встановлення» стає «щоб встановити».
- Виправляє русизми й кальки («на протязі» → «протягом», «згідно наказу» → «згідно з наказом»).
- Скорочує довгі речення і називає, хто діє, замість безособових форм на «-ться».
- Дотримується української типографіки: лапки «», тире за правописом, діапазони «1–3».
- Має окремий режим для службових документів. Реквізити, правові формули, назви актів, номери статей, суми та коди в ньому не змінюються.

Зміст тексту навичка не змінює і нічого від себе не додає.

## Встановлення

Для агентів, що підтримують встановлення навичок з GitHub:

```bash
npx skills add https://github.com/ua50/humanizer-ua
```

Для Claude у браузері або застосунку: завантажте архів репозиторію (Code → Download ZIP) і додайте його як навичку в налаштуваннях Claude.

## Використання

Після встановлення достатньо попросити асистента, наприклад:

- «Виправ цей запит, щоб він не виглядав написаним ШІ»
- «Підготуй довідку за результатами перевірки»
- «Перевір текст на канцелярит, нічого не змінюй»

Асистент поверне виправлений текст і перелік правок за кодами вад (Л1–Л5, Б1–Б6, Т1–Т7, О1–О5). Опис кожного коду є в SKILL.md.

## Скрипт перевірки

`scripts/ua_check.py` працює окремо від асистента. Він знаходить довгі речення, скупчення віддієслівних іменників і безособових форм, штампи, русизми та помилки типографіки. Потрібен лише Python 3, сторонні бібліотеки не потрібні.

```bash
python3 scripts/ua_check.py текст.txt
python3 scripts/ua_check.py --strict текст.txt
```

Скрипт дає підказки, а не висновок. Він не визначає, чи написав текст ШІ.
